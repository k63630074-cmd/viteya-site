Viteya SMS Consent

Viteya event guests may optionally choose to receive text-message updates about an event from Viteya on behalf of the event host.

How guests opt in

  1. The guest opens their personal Viteya event invitation.
  2. The guest selects Continue.
  3. The Text updates section appears.
  4. The guest may enter a U.S. mobile number.
  5. The guest must affirmatively select the SMS consent checkbox to opt in.
  6. The checkbox is unchecked by default.
  7. SMS consent is optional and is not required to RSVP or use the invitation.

Disclosure shown to guests

The invitation shows guests this disclosure:

Text me event updates from Viteya, sent for the host, such as a cancellation or a time change. Message frequency varies. Message and data rates may apply. Reply STOP to cancel and HELP for help.

Viteya does not use this consent for promotional or marketing messages.

SMS consent covers event updates only. It does not currently authorize an initial invitation SMS.
